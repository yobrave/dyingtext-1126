# Last Text at One Percent

One final text message from a dying phone, under 200 characters, judged on humour and dying-phone voice. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
